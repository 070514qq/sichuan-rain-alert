# 中央气象台实况接入与部署

## 已接入来源

用户指定：[中央气象台24小时降水实况](https://www.nmc.cn/publish/observations/24hour-precipitation.html)。它是全国国家级站点降水实况产品，不是四川省单独的实时发布系统。

采集器读取该页面的 `data-time1` 发布时刻，按照页面自身 JavaScript 的十位北京时间参数读取 `/product/realmap/pre_24h/YYYYMMDDHH.json`；1小时产品来自 [1小时降水实况](https://www.nmc.cn/publish/observations/hourly-precipitation.html) 和 `pre_1h`。仅保留 `province=四川` 且 `pcode=ASC` 的站点事实记录。

不运行来源脚本，不抓取站点图像，不复制原站文章。保留来源标注的 `obs_time`，避免把抓取时间冒充观测时间。数据范围是当前产品返回的四川记录；不存在的站点及缺测值不填零，也不代表没有降雨。

## 数据能做什么

- 站点1小时降水、24小时累计降水。
- 最近6个发布时次的1小时实况柱状图，缺失时显示缺失。
- 按24小时实况累计量显示雨量等级与颜色区块。
- 显示采集时间、源观测时间与数据年龄；超过90分钟提示旧数据。这是本产品的展示新鲜度阈值，不是官方预警有效期。

## 城市预测与官方预警

同一官方站点的城市预报页面（例如 https://www.nmc.cn/publish/forecast/ASC/chengdu.html ）展示城市实况和逐三小时预报。通过官网自身使用的 `/rest/province/ASC` 城市目录、`/rest/weather?stationid=目录代码` 取得实况和日预报；逐三小时列从城市页面解析。接入四川21个主要城市/州府条目，目录缺失或失败明确标记。并行请求上限4，不执行源页面脚本。日期跨月、重复时刻、缺失雨量及非连续时间轴均有校验。

开始/结束时段由相邻非雨和雨的预报点构成范围；持续时间上下界由首尾雨点与两侧非雨点计算。只有天气已知且边界足够才展示。首个未来点已经预报有雨时开始未知；结束边界未知时持续未知。`-` 雨量保留缺失，不填零；天气图标仅用来识别预报是否有雨。所有估算是三小时分辨率推算，不能承诺分钟精度或灾害等级。

采集时若官网源发布时间晚于当前5分钟以上，标记时间异常；超过18小时标记预报过期。前端对异常或旧快照暂停时间估算，保留源预报供核对。

官方 https://www.nmc.cn/publish/alarm.html 自身的 `/rest/findAlarm` 列表接口以 `province=四川省`、`signaltype=暴雨` 筛选并读取完整分页。记录显示原标题、蓝/黄/橙/红等级、发布时间、官方原文链接。这里只确认发布记录，尚未核验解除/变更，绝不自行根据实况雨量签发预警。成功空列表表示此次查询没有返回记录；获取失败或过期分别提示，不能表示安全。

模拟版本独立放在 `demo.html`，继续显著标注演示性质。

## GitHub Actions 与 Pages

工作流 `.github/workflows/weather-pages.yml` 每小时第7、22、37、52分钟触发（间隔15分钟，避开整点拥堵），亦支持手动触发和代码推送。

步骤：规则测试 → 准备静态站点 → 采集中央气象台 → 生成 `data/weather.json` → 上传 Pages artifact → 部署。运行时数据不反复提交到 main 分支，不需要长期存储 GitHub 私人令牌或气象接口密钥。

Actions 调度可能延迟或被丢弃；公开仓库长期没有活动时定时任务可能被 GitHub 自动停用。十五分钟是目标调度间隔，不保证严格十五分钟送达。网站每5分钟重新读取已部署快照，不直接跨域抓取源站。

采集失败时生成明确的不可用/部分可用状态并发布，避免网站一直显示没有故障提示的旧数据。部分产品较旧时显示原始时刻，不能改成当前时刻。

## 来源与后续接入

来源网站有数据使用声明，公开访问不等于获得商业再分发许可；正式运营应与来源核对适用授权。本项目不声称已取得商业授权。

后续如需分钟级开始时间、逐小时预报或预警解除状态，应取得相应官方产品和授权；现有逐三小时推算不具备这些精度。
