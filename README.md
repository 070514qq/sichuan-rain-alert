# 四川暴雨预警信息网站

面向四川居民，帮助快速了解本地官方暴雨预警、预测降雨等级、预计开始时间和持续时间。

**项目状态：HTML 演示版。全部气象数据及预警为模拟，尚未接入实时气象数据。**

## 查看演示

- [打开网站](https://070514qq.github.io/sichuan-rain-alert/)
- 本地直接打开 `index.html`，无需安装依赖。
- 支持六个示例地区切换、实况面板、观测与预测降雨图切换、24小时时间轴、预测开始与持续时间、地区色块对比、本机收藏及大字模式。
- 模拟快照固定为 2026-09-27 14:00（北京时间）；页面固定显示演示数据提示，不代表当前真实天气。

## 预期功能

- 按市州、区县查询和收藏地区。
- 展示官方预警等级、发布机构、影响范围、更新时间和原文。
- 展示降雨预测开始时间、预计结束时间与持续时间范围。
- 用颜色区块呈现降雨量大小，并提供文字等级、毫米数和累计时段。
- 提供四川地图和降雨时间轴，适配手机与大字模式。
- 数据过期或接口失败时明确提示，避免误显示“无预警”。

## 开发原则

官方预警与预测降雨分开呈现；不自行签发官方预警。示例数据必须标明“演示数据”；接口密钥不得放进前端或提交到仓库。
